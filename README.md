# ⚙️ Калькулятор допустимого давления конструкций

Промышленное приложение на PyQt5 для расчёта допустимого давления конструкций — используется в реальной production-эксплуатации на предприятии.

> 🔒 \*\*Исходный код закрыт.\*\* Приложение — собственность компании-работодателя, репозиторий содержит только демонстрацию работы (см. `demo.gif` ниже) и описание реализованного функционала. Это осознанное ограничение, а не недоработка: показывать проприетарный код клиента/работодателя без разрешения нельзя.

## Зачем это было нужно

Расчёт допустимого давления вручную требовал профильной квалификации инженера-технолога и был подвержен человеческой ошибке — а цена ошибки в промышленных расчётах высокая. Приложение:

* исключает "человеческий фактор" в расчётах за счёт формализованной проверенной формулы;
* снижает требования к квалификации инженера, выполняющего расчёт (расчёт делает программа, инженер — проверяет и утверждает результат);
* ускоряет сам процесс расчёта на порядок по сравнению с ручным.

## Возможности

* Расчёт допустимого давления по параметрам конструкции
* Сохранение и удаление рассчитанных конструкций в `.xlsx`
* Синхронизация рассчитанных конструкций с облачным хранилищем Google Sheets
* Полноценная работа с базой данных: модели конструкций, заказов и контрагентов
* Автоматическое сохранение рассчитанных данных при расчёте
* Ручное сохранение/редактирование данных в базе
* Выгрузка заказа в формате, пригодном для передачи документов в 1С

## Стек

* **Python, PyQt5** — десктопный интерфейс
* **openpyxl / pandas** — экспорт и работа с `.xlsx`
* **Google Sheets API** — синхронизация с облачным хранилищем
* **SQL-база данных** — модели `Construction`, `Order`, `Counterparty` (конструкции, заказы, контрагенты)

## Роль в проекте

Разработано и сопровождается мной единолично: от расчётной логики и интерфейса до интеграции с Google Sheets, базой данных и выгрузки в формат 1С. Приложение находится в промышленной эксплуатации на предприятии — не пилотный и не учебный проект.

## Почему стоит посмотреть, даже без кода

Демо показывает законченный, действительно используемый в проде инструмент: полный цикл от ручного ввода параметров до сохранения в БД, Excel, облако и передачи в бухгалтерскую систему — то есть не "калькулятор ради калькулятора", а интеграция нескольких систем вокруг одной бизнес-задачи.
